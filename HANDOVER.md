## 1. Project Overview

This project provides SafeHands Insurance Brokers with a basic SOC starter kit for detecting, analyzing, and triaging common security threats.

The project covers the complete workflow from collecting and normalizing security alerts to mapping them to MITRE ATT&CK, creating a Sigma detection rule, and documenting a repeatable SOC triage process.

---

## 2. Project Deliverables

### Alert Normalization

Python Script:  
[View parse_alerts.py](./parse_alerts.py)

Processes the sample SOC logs and converts the alerts into a consistent format for security analysis.

Normalized Alerts:  
[View alerts.json](./alerts.json)

Contains the normalized security alerts generated by the Python script.

---

### MITRE ATT&CK Mapping

MITRE Mapping:  
[View mitre_mapping.csv](./mitre_mapping.csv)

Maps the normalized security alerts to relevant MITRE ATT&CK techniques to help analysts understand the behavior represented by each alert.

---

### Sigma Detection

Sigma Folder:  
[View Sigma Detection Files](./sigma/)

Contains the Sigma detection rule created during Task 3 and the supporting evidence used to test or convert the rule.

---

### SOC Triage Playbook

Triage Playbook:  
[View PLAYBOOK.md](./PLAYBOOK.md)

Provides a step-by-step process for reviewing, validating, investigating, escalating, containing, documenting, and closing security alerts.

---

### Weekly SOC Report

SOC Report:  
[View SOC_Report_Template.md](./SOC_Report_Template.md)

Provides a documented SOC report covering the project's security findings, actions, metrics, recommendations, and overall results.

---

## 4. How to Use This Project

1. Review the sample logs and normalized alerts.
2. Use `alerts.json` for structured alert analysis.
3. Review `mitre_mapping.csv` to understand the MITRE ATT&CK mappings.
4. Review the Sigma rule in the `sigma/` directory for detection logic.
5. Follow `PLAYBOOK.md` when investigating detected activity.
6. Use `SOC_Report_Template.md` to document SOC activity and findings.
