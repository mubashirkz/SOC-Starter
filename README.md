# SOC Analyst Starter Project - SafeHands Insurance Brokers

## Task 1: Alert Collection and Normalization

This project is part of a SOC Analyst starter project for SafeHands Insurance Brokers.

The goal of Task 1 is to process sample SOC log files and convert them into a consistent JSON format that can be used for further security analysis.

## Project Structure

- `logs/` - Contains 20 sample SOC log files.
- `parse_alerts.py` - Python script used to parse and normalize the logs.
- `alerts.json` - Normalized output generated by the Python script.
- `requirements.txt` - Dependency information for the project.

## Normalized Fields

Each normalized alert contains the following fields:

- `timestamp`
- `source_ip`
- `event_type`
- `severity`

## How to Run

Make sure Python 3 is installed.

Open a terminal in the project directory and run:

```bash
python parse_alerts.py
```

The script reads all `.log` files from the `logs/` directory and generates `alerts.json`.

A successful run should display:

```text
Successfully normalized 20 alerts.
Output written to alerts.json
```

## Sample Log Format

```text
2026-09-28 08:15:23 | SRC_IP=192.168.10.25 | EVENT=Failed Login | SEVERITY=Medium
```

## Sample Normalized Alert

```json
{
    "timestamp": "2026-09-28 08:15:23",
    "source_ip": "192.168.10.25",
    "event_type": "Failed Login",
    "severity": "Medium"
}
```

## Log Source

The project brief references a free TryHackMe SOC room as the intended learning resource. However, the supplied brief does not identify a specific downloadable 20-log dataset.

For this implementation, 20 synthetic SOC training logs were created for SafeHands Insurance Brokers. They represent common security events such as failed logins, port scanning, malware detection, suspicious PowerShell activity, phishing, brute-force attempts, and privilege escalation.

These logs are for educational and demonstration purposes and do not contain real client data.

## Requirements

- Python 3
- No external Python packages are required.

The parser uses Python standard libraries only.

The parser successfully processes all 20 sample log files and produces a structured `alerts.json` file containing normalized security alerts ready for further SOC analysis and MITRE ATT&CK mapping.
